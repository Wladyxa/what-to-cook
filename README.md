# Что приготовить 🍲

Домашняя PWA для iPhone: нажимаешь кнопку и получаешь три идеи, что приготовить. У каждого блюда есть рецепт по шагам, КБЖУ на порцию и на всё блюдо, примерная стоимость и список покупок с ценами в рублях.

## Что умеет

- **Встроенная книга рецептов**: 51 блюдо (завтраки, супы, горячее, салаты, десерты). КБЖУ считается автоматически из граммовок, цены взяты как ориентир по сетевым супермаркетам РФ.
- **Три варианта по кнопке**, с фильтрами: категория, «до 30 минут», «полезное», «до 450 ккал».
- **Любимое**: сердечко у блюда. Похожие блюда подбираются по категории, тегам и основным продуктам. «Не предлагать» скрывает блюдо.
- **Список покупок**: собирает продукты из нескольких блюд, группирует по отделам магазина, считает сумму, умеет отправлять список через «Поделиться».
- **ИИ (по желанию)**: в разделе «Ещё» вставляешь ключ OpenRouter и выбираешь модель. На главной появится «Придумать новое с ИИ». Ключ хранится только на устройстве.
- Работает офлайн, поддерживает тёмную тему.

## Установка на iPhone

1. Открой ссылку на приложение в Safari.
2. Нажми «Поделиться» → «На экран Домой».

## Разработка

Без сборки и зависимостей: обычные HTML, CSS и JS.

```
npx http-server . -p 8080
```

- `recipes.js`: продукты (КБЖУ на 100 г, упаковка, цена) и рецепты.
- `app.js`: логика и экраны.
- `sw.js`: офлайн-кэш. Когда меняешь файлы, увеличь `CACHE`.

Чтобы добавить рецепт, допиши `r(...)` в `RECIPES`, используя ключи из `PRODUCTS`.
